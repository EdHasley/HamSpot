# Menu status

Implemented: dashboard, DMR radio setup, saved XLX reflectors and ports, host-file submenu, diagnostics, service start/stop, configuration backup/restore, light/dark theme.

Host-file submenu supports DMR/XLX, DCS, XRF and REF editing/download. Only DMRGateway is installed and consumes its host list. D-Star host files are saved for future gateway integration.

Not implemented: other mode gateways, physical Nextion, HDMI kiosk setup, Wi-Fi/network administration, firewall editing, cross-mode audio, update/uninstall and full menu parity. Feature status is visible in the application. These controls must not be represented as working until integrated and verified.
