# Nextion Enhanced NX4832K035 target

User-confirmed physical touchscreen: Nextion Enhanced NX4832K035, 3.5-inch 480x320, four-wire TTL serial. Installed on spare Raspberry Pi 5 hotspot with MMDVM duplex HAT.

## Firmware/display target
- Create an editable Nextion Editor HMI project for **NX4832K035** at **480 x 320**.
- Compile the corresponding model-specific TFT firmware using Nextion Editor and test on the actual display.
- Page 0: live mode, callsign, reflector, talkgroup, RX/TX and network status.
- Page 1: connection/status detail and navigation.
- Page 2: simple touch actions, with confirmation and authorization as appropriate.
- Web UI remains the primary full settings interface, no terminal needed for normal use.

## Serial integration
- Four-wire 5V, GND, TX, RX; verify physical wiring and electrical levels against manufacturer specs.
- Nextion UART must not be conflated with the MMDVM modem UART. Determine which connector/serial path is wired.
- Baud rate configurable, auto-detect only where safe; verify serial port availability on Pi 5.
- Build a daemon that reads radio state and sends Nextion protocol frames (commands terminated by FF FF FF), with touch event handling.
- No finished HMI/TFT or hardware-tested serial daemon is currently available.

## Test sequence
1. Identify actual wired serial device and check power.
2. Confirm Nextion model and firmware revision.
3. Compile NX4832K035 HMI to TFT and deploy through supported update method.
4. Validate text updates and touch events on physical hardware.
5. Validate concurrent modem operation on the Pi 5.

Keep the working Pi 4 hotspot unchanged during testing.
